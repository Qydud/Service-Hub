# ServiceHub

ServiceHub — корпоративный сайт для приёма заявок на сервисные услуги.

## Первая версия

Сайт соответствует ТЗ проекта ServiceHub v1.0:

- Главная
- Услуги
- О компании
- Контакты
- Форма заявки
- Административная панель
- Статусы заявок: **Новая**, **В работе**, **Выполнена**
- Поиск заявок в админ-панели
- Загрузка фото объекта

Услуги:

- Клининг
- Ремонт
- Электрика
- Сантехника
- Транспорт
- Спецтехника
- Озеленение

## Технологии

- React + Vite
- FastAPI
- PostgreSQL
- SQLAlchemy
- Alembic
- Docker Compose
- Nginx
- JWT для административного доступа

## Запуск

1. Создайте `backend-stem/.env` на основе `backend-stem/.env.example`.
2. Запустите Docker Desktop.
3. Выполните:

```powershell
docker compose up -d --build
```

4. Для создания администратора после запуска backend:

```powershell
docker exec servicehub_backend python create_admin.py
```

Администратор использует `ADMIN_EMAIL` и `ADMIN_PASSWORD` из `.env`.

## Важно

Проект развивается независимо от исходного STEM-сайта. В текущей ветке отсутствуют его товарный каталог, корзина, Bitrix24, визуализация, блог и соответствующие миграции.
